# /search-all-sources

**LAYER 1: RESEARCH AGENT** — You MUST read and follow `docs/sources/_preamble.md` before starting. Report what each source returns. Do not interpret or apply frameworks.

Search a term across every available data source. Now probe-first: runs recon to identify which sources have data, then does full searches only on sources with hits.

## Arguments

- Required: search term (e.g., `/search-all-sources churkin ambassador`)

### Context Loading
```bash
uv run python tools/investigation_context.py show
```

## Process

### 0. Session Setup
```bash
WORKDIR=$(mktemp -d /tmp/osint-XXXXXXXX)
echo "Session workdir: $WORKDIR"
```

### 1. Recon Probe

Run the recon probe first to identify which sources have data:
```bash
uv run python tools/recon_probe.py probe "<QUERY>" --output $WORKDIR/recon.json
```

Read the output. Focus full searches on sources in the `high` and `medium` heat map tiers. Skip `zero` sources unless there's a strong reason to double-check.

### 2. Run Full Searches (Sources With Hits)

For each source with data, use the relevant source module protocol:

**Source modules** (read for protocol):
- `docs/sources/corpus.md` — investigation corpus tools
- `docs/sources/courtlistener.md` — federal courts
- `docs/sources/edgar.md` — SEC filings
- `docs/sources/fec.md` — campaign finance
- `docs/sources/990.md` — nonprofit filings
- `docs/sources/lobbying.md` — LDA + FARA
- `docs/sources/registry.md` — corporate registries + UCC
- `docs/sources/littlesis.md` — power network
- `docs/sources/aleph-icij.md` — offshore leaks
- `docs/sources/usaspending.md` — federal spending + SAM + HigherGov
- `docs/sources/gdelt-web.md` — news + web search
- `docs/sources/sanctions.md` — OpenSanctions
- `docs/sources/infrastructure.md` — Shodan, crt.sh, Wayback, URLScan
- `docs/sources/acris-ucc-property.md` — property records
- `docs/sources/gleif-ds10.md` — LEI + financial records
- `docs/sources/offshorealert.md` — offshore court cases + regulatory actions

Use `--output $WORKDIR/search-<source>.json` on ALL searches.

### 3. Investigation Corpus Tools (from profile)

Search any investigation-specific corpus tools listed in `corpus_tools` from the profile:
```bash
uv run python tools/<corpus_tool>.py search "<QUERY>" --limit 20 --output $WORKDIR/search-<source>.json
```

### 4. Log Each Search

```python
from tools.lead_tracker import log_search
log_search("<QUERY>", "source_name", result_count)
```

### 6. Analytical Assessment

- **What did you expect to find vs. what you found?** Surprises are intelligence.
- **Cross-bureaucratic correlation**: Results from independent sources converging on the same event.
- **New names and entities**: Flag previously unknown persons, emails, corporate entities.
- **Timeline patterns**: Results clustering around specific dates.

### 7. Suggest Follow-Up

- Whether findings warrant creating a lead
- Which sources still need deeper investigation
- Cross-references to investigate
- Hypotheses generated by the results
- What's conspicuously absent
