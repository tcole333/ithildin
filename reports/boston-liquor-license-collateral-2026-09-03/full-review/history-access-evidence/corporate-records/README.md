# Corporate-records access evidence

This package preserves previously saved web-tool responses from the September 4, 2026 research. No new network request, portal search, paid API call or contact occurred during packaging.

The [manifest](manifest.json) lists each official source URL, retrieval date, local capture path, size and SHA-256 hash. Its 15 source entries cover the corporate bulk regulation and catalog, filing-fee information, ordinary and professional annual-report forms/instructions, division and records-officer contacts, public-records rules and website-terms metadata.

**These are web-tool text/metadata captures, not downloaded source PDFs or HTML files.** The tool may have returned only excerpts. In particular, the 950 CMR 113 evidence preserves its bulk-product search excerpt and partial PDF text output; it is not the full 26-page original PDF. The website-terms capture contains metadata/find output only and does not preserve the substantive terms text read in another response.

The local hashes authenticate these packaged JSON bytes, not the remote originals. Each JSON also identifies its previous saved-response file and hash and retains the relevant web-tool output. Exact original retrieval times were not saved; the recorded date has day precision. This package neither fills omitted source text nor certifies the published fees as a current supplier quote.

Key captures: [950 CMR 113](captures/950-cmr-113.json), [corporation annual report](captures/corporation-annual-report.json), [LLC annual report](captures/llc-annual-report.json), [LLC instructions](captures/llc-instructions.json), [professional-corporation instructions](captures/professional-corporation-instructions.json), [division contact](captures/division-contact.json), [RAO guidelines](captures/public-records-guidelines.json).
