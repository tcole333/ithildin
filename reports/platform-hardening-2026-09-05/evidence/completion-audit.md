## Material boundaries to retain

- **Publication remains blocked.** The current-content snapshot check now reports contextual data debt rather than crashing: 534 source files, 116 eligible finding IDs, 32,446 issue occurrences/references, and no snapshot materialized. Those issues are not 32,446 distinct findings. Examples are null evidence on Conductor findings 11472, 11475, 11505, 11471, 11517 and synthesis/high on Anduril findings 4565/4577. No historical statuses, facts, quotes, or semantic PASS receipts were fabricated.
- **Snapshot authority is versioned content authority.** CI validates the self-contained reviewed content artifact; it does not query the live investigation database. Retractions/corrections propagate through an audited candidate refresh and invalidate changed content/reviews. A static release is not continuous live-DB synchronization. The candidate builder supplies `--db`; the standalone snapshot CLI also permits an explicitly DB-free build/check. Schema-1 older exports may omit `source_datasets`, so that metadata's source-specific cap is checked only when supplied. This compatibility limit should remain explicit.
- **Semantic receipts prove version binding and review structure, not truth.** A reviewer must actually read the supporting evidence. Deterministic queue editor checks and structural citation checks do not replace semantic review. Existing publication debt is separate follow-up content work, not an unfinished code fix or permission to bypass the gate.
- **Execution controls are bounded.** Staged work still has canonical DB/tool access under a prompt contract; it is not an OS/database sandbox. Opting out of staged review removes that guarantee. Cost caps remain soft; in-process Python cancellation is cooperative; process groups do not cover deliberately detached sessions. Idempotency applies to import of the same staged run, not universal external worker side effects. Legacy active runs without exit receipts fail closed, and legacy unpinned research queue jobs need explicit re-enqueueing.
- **Simplification is representative.** The Lincoln WFS API migration and four logging-wrapper integrations do not claim to replace every legacy CLI translation/environment parser. The review sampled source families and did not survey live endpoint health or perform a security audit.
- **Git ownership remains visible.** Seven coherent commits existed at audit time through `57d23c0d`; many completed implementation paths were still unstaged. `reports/epstein-restart-2026-09-05/` is unrelated concurrent work and must not be swept into this task or hidden to claim a clean tree.
