# /investigate-person

**LAYER 1: RESEARCH AGENT** — You MUST read and follow `docs/sources/_preamble.md` before starting. It defines evidence standards, entity registration, and report format.

Deep-dive investigation of a named individual across all available data sources.

## Arguments

- Required: person name (e.g., `/investigate-person Samantha Rose Stein`)

**Read `research/INVESTIGATIVE_METHODOLOGY.md` before your first investigation.**

### Context Loading
```bash
uv run python tools/investigation_context.py show
```

## Process

### 0. Session Setup
```bash
WORKDIR=$(mktemp -d /tmp/osint-XXXXXXXX)
echo "Session workdir: $WORKDIR"
```

### 1. Know Your Subject Before You Search

**This is the most important step.** Before querying any database, use your training data:

- **Who is this person in the world?** Public biography, position, known affiliations. A Goldman Sachs General Counsel is different from an obscure PR consultant.
- **What's their known role in the network?** Published reporting, court filings, media coverage — what's the public narrative? Your job is to test whether documentary evidence supports, contradicts, or complicates that narrative.
- **Form explicit hypotheses.** Write them down:
  - "Hypothesis: the relationship was transactional — Subject A wanted institutional access"
  - "If correct, I'd expect to see: emails about introductions, invitations to events"
  - "If wrong, I'd expect to see: purely social/casual correspondence"

**Simulate the person:**
- What did they want from the network? (access, legitimacy, information, money, political cover)
- What could the network offer them?
- What was their public position vs. private behavior? The gap is where the story lives.
- Where do they sit in the network topology? Hub? Intermediary? Peripheral?

**Check international context.** For Israeli connections, consider Hebrew-language media. For Russian connections, understand *siloviki* vs. *oligarch* dynamics. Try native-language name forms and alternate transliterations.

### 2. Web Background Research

Before databases, research the subject's public profile:

```
WebSearch: "<NAME>" — basic biography
WebSearch: "<NAME>" {primary_subject} — known connections
WebSearch: "<NAME>" investigation lawsuit scandal
WebSearch: "<NAME>" site:littlesis.org
```

If Wikipedia page exists, WebFetch it. Check `research/RELATED_INVESTIGATIONS.md` and `research/OSINT_RESOURCES.md`.

### 3. Check Existing Knowledge
```bash
uv run python tools/findings_tracker.py list --target "<NAME>" --output $WORKDIR/inv-findings.json
uv run python tools/lead_tracker.py search "<NAME>" --output $WORKDIR/inv-leads.json
```

### 4. Search All Sources

Run `/search-all-sources <NAME>` for comprehensive results, OR manually search relevant sources based on the person's profile.

**Source modules** — read the relevant ones for protocol:
- Person background: `docs/sources/gdelt-web.md`, `docs/sources/littlesis.md`
- Financial footprint: `docs/sources/fec.md`, `docs/sources/edgar.md`, `docs/sources/990.md`
- Legal history: `docs/sources/courtlistener.md`
- Corporate roles: `docs/sources/registry.md`
- Government ties: `docs/sources/lobbying.md`, `docs/sources/usaspending.md`
- Sanctions/PEP: `docs/sources/sanctions.md`
- Investigation corpus: `docs/sources/corpus.md`

Additionally, search for known aliases, maiden names, alternate transliterations, and associated email addresses.

### 5. Entity Co-occurrence Analysis

```bash
uv run python tools/query_lmsband.py cooccurrence "<NAME>" --top 30 --output $WORKDIR/inv-coocc.json
uv run python tools/query_unified.py cooccurrence "<NAME>" --top 30 --output $WORKDIR/inv-unified-coocc.json
uv run python tools/query_unified.py triples --actor "<NAME>" --limit 30 --output $WORKDIR/inv-triples.json
```

### 6. Record Findings

See `docs/sources/_preamble.md` for evidence standards, entity registration, and career arc recording commands.

### 7. Analyze What's Missing

- **Communication gaps**: If emails span 2016-2017 but nothing in 2018-2019, why?
- **The "both sides" pattern**: Who else communicates with someone adversarial to this person?
- **Coded language**: Flag euphemisms that don't fit context.
- **Intermediary patterns**: If communications go through gatekeepers, ask why.
- **Timeline context**: Map key events against communication patterns.

### 8. Spawn Follow-Up Leads

Create leads for:
- Unexplored connections from co-occurrence analysis
- Financial trails needing tracing
- Entities not yet traced through ICIJ
- New hypotheses generated by the investigation

### Report File (when running as sub-agent)

Write to `$WORKDIR/report-investigate-<name-slug>.md` using the format in `docs/sources/_preamble.md`.

After writing, ingest learnings:
```bash
uv run python tools/methodology_tracker.py ingest-report "$WORKDIR/report-investigate-<name-slug>.md" --skill investigate-person
```
