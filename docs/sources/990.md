# ProPublica 990 & IRS 990 Bulk (Nonprofit Tax Filings)

## ProPublica API

**URL:** https://projects.propublica.org/nonprofits/api
**Auth:** None | **Tool:** `tools/query_990.py` | **Citation prefix:** `990:EIN`
**Coverage:** 2011 — present (electronic filings)

```bash
uv run python tools/query_990.py search "ORG NAME" --output $WORKDIR/990-search.json
uv run python tools/query_990.py org EIN --output $WORKDIR/990-org.json
uv run python tools/query_990.py filings EIN --output $WORKDIR/990-filings.json
```

## IRS 990 Bulk Grants (Local DB — 22M+ grants)

**DB:** `datasets/irs990_grants.db` (FTS5)
**Auth:** None (local) | **Tool:** `tools/query_990_bulk.py`

```bash
# Full-text search grants + related orgs
uv run python tools/query_990_bulk.py search "TARGET" --output $WORKDIR/990-bulk-search.json
# Grants made by a filer
uv run python tools/query_990_bulk.py filer EIN --output $WORKDIR/990-bulk-filer.json
# Grants received by name
uv run python tools/query_990_bulk.py recipient "ORG NAME" --output $WORKDIR/990-bulk-recipient.json
# Grant network (BFS from seed EIN)
uv run python tools/query_990_bulk.py network EIN --depth 2 --output $WORKDIR/990-bulk-network.json
# Co-grantors (who else funds the same recipient?)
uv run python tools/query_990_bulk.py co-grantors EIN --output $WORKDIR/990-bulk-cograntors.json
# Cross-reference against investigation entities
uv run python tools/query_990_bulk.py cross-ref --output $WORKDIR/990-bulk-crossref.json
```

## Protocol

1. Search ProPublica for organization name
2. For each match, pull full org details and filings by EIN
3. Search 990 bulk for grant flows (filer + recipient)
4. Map grant network for key EINs
5. Check filing history — Schedule I (grants made), Part VII (officer compensation)
6. Cross-reference officers with entity_tracker

## What To Look For

- **Grant flows**: Who is this nonprofit funding? Who funds them?
- **Officer compensation**: Excessive compensation relative to org size
- **Officer overlap**: Same people running multiple nonprofits (network mapping)
- **Revenue patterns**: Sudden spikes/drops in revenue or assets
- **Program service vs. grant ratio**: How much goes to actual programs vs. re-granting?
- **Related organizations**: Part IV reveals affiliated entities
