# ProPublica 990 (Nonprofit Tax Filings)

**URL:** https://projects.propublica.org/nonprofits/api
**Jurisdiction:** United States
**Auth:** None
**Tool:** `tools/query_990.py`
**Citation prefix:** `990:EIN`

## Access

- **Method:** REST API
- **Rate limits:** No published limit; be respectful
- **Cost:** Free
- **Coverage dates:** 2011 — present (electronic filings)

## Subcommands

```bash
uv run python tools/query_990.py search "ORG NAME" --output $WORKDIR/990-search.json
uv run python tools/query_990.py org EIN --output $WORKDIR/990-org.json
uv run python tools/query_990.py filings EIN --output $WORKDIR/990-filings.json
```

## Protocol

1. Search for organization name
2. For each match, pull full org details by EIN
3. Check filing history — look at Schedule I (grants made), Part VII (officer compensation)
4. Cross-reference officers with entity_tracker

```bash
uv run python tools/query_990.py search "TARGET" --output $WORKDIR/990-search.json
# For each EIN found:
uv run python tools/query_990.py org EIN --output $WORKDIR/990-org-EIN.json
uv run python tools/query_990.py filings EIN --output $WORKDIR/990-filings-EIN.json
```

## What To Look For

- **Grant flows**: Who is this nonprofit funding? Who funds them?
- **Officer compensation**: Excessive compensation relative to org size
- **Officer overlap**: Same people running multiple nonprofits (network mapping)
- **Revenue patterns**: Sudden spikes/drops in revenue or assets
- **Program service vs. grant ratio**: How much goes to actual programs vs. re-granting?
- **Related organizations**: Part IV reveals affiliated entities
