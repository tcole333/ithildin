# Drexel Network Investigation

Investigation into the Drexel Burnham Lambert junk bond network of the 1980s, including:
- The Milken inner circle at Drexel
- Corporate raiders financed by Drexel ("Raiders Club")
- Stock parking networks (Boesky, Jefferies, etc.)
