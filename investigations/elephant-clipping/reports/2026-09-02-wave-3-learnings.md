## Learnings

- [Methodology] Date an archived page's outbound application link separately from the currently retrieved form schema; the historical destination does not authenticate historical pricing, and current offer wording does not establish a sale or revenue. Derived from agent A and organization/provenance QA.
- [Methodology] Legal wording may be supplied in ordinary public HTML page data while a linked client merely references it; inspect the already-served source before assuming the field is absent or inventing another route. Derived from agent A.
- [Methodology] A current content-hub 404 can be complemented by sparse archives, but inspect each recovered page and preserve the temporal gaps and unreviewed linked-article population. Derived from agent B.
- [Source quality] Empty caption/audio acquisition files establish missing comparison bytes; their hashes do not independently authenticate collector-transcribed HTTP outcomes or disprove the historical source. Derived from agent B and artifact QA.
- [Methodology] Empty or nonsensical OCR may reflect the wrong crop; visually inspect corrected frames before using extracted text or interpreting its absence. Derived from agent B.
- [Methodology] Distinguish generation, shared source material, collection of already-published posts, reward submission and social publication; a public client description is not observed server execution. Derived from agent D and money/tools QA.
- [Source quality] A changelog has an internal identifier, displayed date text and independently observed availability; preserve those dates separately and do not convert a self-dated political-feature claim into a verified release or named-campaign deployment. Derived from agent D and money/tools QA.
- [Source quality] A pseudonymous payment claim on another host is not automatically independent corroboration; preserve its original post, platform-transition caveat and unverified identity, and count quoted repetitions as one provenance chain. Derived from agent D and money/tools QA.
- [Methodology] Current public dependency manifests can resolve stale static filenames; a prior missing asset does not establish a missing feature when an ordinary page explicitly links a current asset. Derived from agent D.
- [Methodology] When a reader supplies source text but direct HTTP returns a challenge, retain both acquisition outcomes and never attach the challenge body as provenance for the reader's quote. Derived from money/tools QA.
- [Methodology] Identify the authoritative contact sheet, sampling rate, populated-frame count and padding explicitly when the workdir contains earlier diagnostic sheets with different sampling. Derived from organization/provenance QA.
- [Methodology] Establish each campaign-finance portal's filer population before describing state coverage; an all-county local BOE search is not a statewide candidate, PAC or party search. Derived from agent C and the Ohio helper.
- [Source quality] Positive controls help test a zero-result workflow, but beta-interface warnings, blank payee fields and partial control pagination still limit source completeness and identity resolution. Derived from agent C.
- [Process gap] Payment-search evidence should distinguish errors, unissued selectors, matching semantics, date/report scope, cursor exhaustion and amendment flags; exact query counts are not exact-name matching or proof of absent transactions. Derived from agent C.
- [Methodology] Transfer a verified public route to a single query owner when another browser cannot reliably expose controls; keep navigation-only assistance separate from the owner's actual filtered search pass. Derived from the Ohio helper and agent C.
- [Methodology] Same-source preservation links should have a separate audited receipt and explicit non-corroboration assessment while retaining the original evidence references. Derived from artifact QA.
