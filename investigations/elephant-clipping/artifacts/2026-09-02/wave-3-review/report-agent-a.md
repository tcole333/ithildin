## Learnings

- [Methodology] A historical page linking a current form authenticates the historical destination, not the current form's contents at the historical date. State the two observation dates separately before drawing any business-model conclusion.
- [Source quality] A publisher's four-figure coaching offer can document a separate proposed revenue channel while proving no customer, exact price, sale, revenue amount or campaign-funding explanation.
- [Methodology] Legal-party wording may be supplied in the ordinary public HTML page-data object while a linked JavaScript file only references it. Inspect the already-served page before inventing another endpoint or assuming the field is missing.
- [Source quality] Exact query text in a search box does not establish exact query execution. Three Bing pages here returned entirely unrelated destinations, while Brave and Yahoo supplied HTTP errors; none supports index-wide absence.
- [Friction] Papercut 2604 records a read-only audit's mistaken optional search_log column; live schema inspection and a corrected query resolved it without code changes. Papercut 2608 records an exact Wayback legal-index HTTP 503 without an output artifact; it remains a source/tool reporting gap, not an empty index.
