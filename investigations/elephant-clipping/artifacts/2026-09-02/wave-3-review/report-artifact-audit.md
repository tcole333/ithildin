## Learnings

- [Methodology] Validate the contents of a durable artifact against a positive field allowlist; a filename containing reviewed or sanitized does not establish that unrelated search-result payloads were removed.
- [Methodology] A concurrent profile audit needs an explicit commissioned finding-ID allowlist, and preservation-audit exports need an explicit correction-ID allowlist, so unrelated workers are not silently incorporated into a wave's results.
- [Source quality] A hash of an empty acquisition file confirms missing bytes, not a collector-transcribed HTTP status; preserve that distinction in the manifest and review verdict.
- [Methodology] Same-source preservation links should retain a separate audit receipt and an explicit non-corroboration assessment while leaving the original source references intact.
