## Learnings

1. Hingham appearances have multiple meanings: actual Pinecrest title, the Hassull trust's Hingham address, and Malloy & Sullivan recorder mailback addresses. A city string alone cannot identify property ownership.
2. Compressed registry searches can return expanded names and duplicate party rows. The SAM prefix produced Samuel namesakes, demonstrating why record counts are not target assets.
3. Exact trust searches recovered deeds omitted from the Hicham person index. Each vehicle requires its own index search to reconstruct a title interval.
4. Recorder indexing can abbreviate capacities or contain misleading party labels; original grant language and immediate prior-title recitals resolve the chain.
5. The UI retains the preceding successful result list when a new search yields a zero-hit modal. Search outcomes were checked against the modal rather than misreading that stale list.
6. Snapshot years must come from actual dataset rows, not a stale retrieval manifest or a municipal value heading. Helper logged repository papercut 2699 for that discrepancy.
